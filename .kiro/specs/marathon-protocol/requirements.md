# Marathon Challenge Protocol - Requirements Document

## Introduction

Marathon Challenge Protocolは、マラソンランナーが大会への参加を宣言し、目標を設定し、結果を記録してNFTとして永続化するシステムです。従来のマラソン記録管理とは異なり、事前の目標宣言と達成度評価を組み合わせることで、挑戦のストーリー全体を価値あるデジタル資産として保存します。

## Requirements

### Requirement 1: 大会参加宣言システム

**User Story:** マラソンランナーとして、参加予定の大会を事前に宣言し、自分の目標を明確にしたい。そうすることで、挑戦への本気度を高め、後から振り返れる記録を作りたい。

#### Acceptance Criteria

1. WHEN ユーザーが新しい挑戦を作成する THEN システムは大会名、開催日、目標タイプの入力を求める
2. WHEN ユーザーが目標タイプを選択する THEN システムは「完走」「サブ4」「サブ3.5」「サブ3」「自由設定」の選択肢を提供する
3. WHEN ユーザーが自由設定を選択する THEN システムは具体的な目標タイム（時:分:秒）の入力を求める
4. WHEN 宣言が完了する THEN システムは一意のチャレンジIDを生成し、宣言内容を不変的に記録する
5. WHEN 宣言が記録される THEN システムは宣言日時とユーザーIDを含む完全な宣言データを保存する

### Requirement 2: 結果記録・証拠提出システム

**User Story:** マラソン完走後のランナーとして、自分の記録を正確に登録し、それを証明する証拠を提出したい。そうすることで、信頼性の高い記録として永続化したい。

#### Acceptance Criteria

1. WHEN ユーザーが結果登録を開始する THEN システムは既存の宣言一覧から対象チャレンジの選択を求める
2. WHEN ユーザーが完走タイムを入力する THEN システムは時:分:秒形式での入力を受け付ける
3. WHEN ユーザーが証拠画像をアップロードする THEN システムは完走証、リザルト画面、公式記録の画像を受け付ける
4. WHEN 画像がアップロードされる THEN システムは画像を安全に保存し、改ざん防止のためのハッシュを生成する
5. WHEN 結果が未完走の場合 THEN システムは「DNF（Did Not Finish）」の選択肢を提供し、理由の入力を可能にする

### Requirement 3: 目標達成度判定・NFT生成システム

**User Story:** 記録を提出したランナーとして、自分の目標達成度を客観的に評価され、それに応じた記念NFTを受け取りたい。そうすることで、挑戦の成果を可視化し、次への動機にしたい。

#### Acceptance Criteria

1. WHEN 結果が提出される THEN システムは宣言された目標と実際の記録を比較し、達成度を判定する
2. WHEN 目標を達成した場合 THEN システムは「GOAL ACHIEVED」ステータスの金色メダルNFTを生成する
3. WHEN 完走したが目標未達成の場合 THEN システムは「COMPLETED」ステータスの銀色メダルNFTを生成する
4. WHEN 未完走の場合 THEN システムは「CHALLENGED」ステータスの銅色メダルNFTを生成する
5. WHEN NFTが生成される THEN システムは大会名、日付、目標、結果、達成ステータスを含むメタデータを埋め込む
6. WHEN NFTが完成する THEN システムはユーザーのウォレットに自動的に発行する

### Requirement 4: 記録管理・可視化システム

**User Story:** 複数のマラソンに挑戦するランナーとして、自分の全ての記録を一覧で確認し、成長の軌跡を可視化したい。そうすることで、過去の挑戦を振り返り、将来の目標設定に活用したい。

#### Acceptance Criteria

1. WHEN ユーザーがダッシュボードにアクセスする THEN システムは全ての挑戦記録を時系列で表示する
2. WHEN 記録一覧が表示される THEN システムは各記録の大会名、日付、目標、結果、達成ステータスを表示する
3. WHEN ユーザーが統計を確認する THEN システムは総挑戦回数、完走回数、目標達成回数、平均タイムを表示する
4. WHEN ユーザーがタイム推移を確認する THEN システムはグラフ形式でタイムの変化を可視化する
5. WHEN ユーザーが個別記録を選択する THEN システムは詳細情報と証拠画像、NFTを表示する

### Requirement 5: ユーザー認証・プロフィール管理システム

**User Story:** システムを利用するランナーとして、安全にログインし、自分のプロフィール情報を管理したい。そうすることで、記録の所有権を明確にし、長期的に利用したい。

#### Acceptance Criteria

1. WHEN 新規ユーザーがアクセスする THEN システムはウォレット接続による認証を提供する
2. WHEN ユーザーがウォレットを接続する THEN システムは署名による本人確認を実行する
3. WHEN 認証が完了する THEN システムはユーザー固有のプロフィールページを作成する
4. WHEN ユーザーがプロフィールを編集する THEN システムはランナー名、目標、自己紹介の編集を可能にする
5. WHEN プロフィール情報が更新される THEN システムは変更内容を安全に保存し、NFTメタデータに反映する
