# Marathon Challenge Protocol

このプロジェクトは [Kiro](https://kiro.ai) を使用して開発されました。
Kiro は AI アシスタントによる効率的な開発を可能にするツールです。

マラソンランナーが大会への参加を宣言し、目標を設定し、結果を記録してNFTとして永続化するシステムです。従来のマラソン記録管理とは異なり、事前の目標宣言と達成度評価を組み合わせることで、挑戦のストーリー全体を価値あるデジタル資産として保存します。

## 🌟 特徴

- **宣言→実行→結果→確認のプロトコル**: マラソンチャレンジの全工程を管理
- **目標設定システム**: 完走、サブ4、サブ3、カスタム目標に対応
- **証拠ベース記録**: 完走証などの画像アップロードによる信頼性確保
- **NFTメダル発行**: 達成度に応じた3段階のメダル（金・銀・銅）
- **ウォレット認証**: MetaMaskによる署名認証システム
- **統計・可視化**: 個人の成長記録とタイム推移の表示

## 🚀 主な機能

### 🏃‍♂️ チャレンジ宣言
- 大会名と開催日の登録
- 目標タイプの選択（完走/サブ4/サブ3/カスタム）
- 事前コミットによるモチベーション向上

### 📊 記録管理
- 完走証画像のアップロード
- タイム記録と目標達成度の自動判定
- 個人統計とタイム推移の可視化

### 🏅 NFTメダル
- 達成度に応じたメダルNFTの自動発行
- 挑戦のストーリー全体をデジタル資産として永続化
- コレクション表示とソーシャル共有

## 🚀 クイックスタート

### 1. 基本セットアップ

```bash
# リポジトリをクローン
git clone <repository-url>
cd marathon-challenge-protocol

# 依存関係をインストール
npm install

# 開発サーバーを起動（プレビューモード）
npm run dev
```

ブラウザで http://localhost:3000 を開いてプレビューを確認できます。

### 2. 完全版セットアップ（本格運用）

```bash
# 環境変数を設定
cp .env.example .env.local

# .env.local を編集して以下を設定:
# - データベース情報 (MySQL)
# - Alchemy API キー
# - Pinata IPFS キー
# - JWT シークレット
# - プライベートキー（セキュア管理）

# データベースマイグレーション
npm run db:migrate

# 開発サーバーを起動
npm run dev
```

### 3. プレビューモード

ウォレット接続なしでも以下の機能を確認できます：
- ✅ チャレンジ作成フォーム
- ✅ 結果記録フォーム  
- ✅ NFTコレクション表示
- ✅ ダッシュボード
- ✅ 統計表示

## 🔧 環境変数

`.env.example` を参考に以下の環境変数を設定してください：

- `NEXT_PUBLIC_CHAIN_ID`: 使用するブロックチェーンのチェーンID
- `NEXT_PUBLIC_RPC_URL`: RPC エンドポイント
- `QUEST_PASSPHRASE`: クエスト用の合言葉
- `QUEST_REWARD_AMOUNT`: クエスト報酬額

## 🎮 使用方法

### 管理者向け - 合言葉設定

1. `.env.local` の `QUEST_PASSPHRASE` を設定
2. `QUEST_REWARD_AMOUNT` で報酬額を調整
3. アプリケーションを再起動

### ユーザー向け

1. **ホームページ**: 機能概要を確認
2. **クエスト**: 合言葉を入力してトークンを獲得
3. **クレーム**: 獲得したトークンをクレーム

## 🎯 実装済み機能

### ✅ コア機能
- **チャレンジ宣言システム** - 大会参加の事前宣言と目標設定
- **結果記録システム** - 画像証拠付きの記録提出
- **達成度判定** - 自動的な目標達成度評価
- **NFTメダル発行** - 達成度に応じた3段階メダル
- **ウォレット認証** - MetaMask署名による認証
- **プロフィール管理** - ユーザー情報と統計表示

### ✅ 技術実装
- **フロントエンド**: Next.js 15 + TypeScript + Tailwind CSS
- **認証**: JWT + ウォレット署名
- **データベース**: MySQL対応（開発時はモック）
- **ブロックチェーン**: Ethereum + Alchemy統合準備済み
- **ストレージ**: IPFS (Pinata) 対応
- **NFT**: ERC-721準拠スマートコントラクト

### ✅ セキュリティ
- **環境変数管理** - 秘匿情報の適切な分離
- **サーバーサイド専用** - 重要な処理のサーバー限定
- **入力検証** - 包括的なバリデーション
- **エラーハンドリング** - 適切なエラー処理
